# Antre onboarding - anonymous-first local concept

This branch adds a single calm first-run screen. Visitors can choose to explore works or see the seven experiences without email, camera or location permission. The choice is stored only in browser localStorage for this prototype; it is not an account, consent to profiling, or Firebase identity. No user input is transmitted. Camera and location should be requested contextually in their own later features, with manual alternatives. The example illustration is abstract placeholder art, not a licensed artwork.

The next Feed branch will connect Explore to the limited guest discovery window; the seven feature panels remain labelled concepts. Review accessibility, text legibility on iPhone-sized screens, focus order, screen-reader output and a fresh-browser first run. This is not a shipped iOS onboarding flow.
